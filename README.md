# ON SITE

Public event-rental catalogue. Polish is the default language. English is a cookie switch (`onsite-lang`).

The catalogue has no prices and no payment. The basket and the request form are on `/quote`. A saved request stays in the browser. It is not sent, and it does not reserve the equipment. A company email address is not published.

Product photos are the published hero images from dyzurek.com. Lines the public site does not publish are left out. The catalogue has no stock counts.

```bash
npm run dev
npm run lint
node scripts/check-claims.mjs
```
